# 10: 完成 Skill 分发与 Claude Code 端到端试点

**What to build:** 让用户可以通过标准 Skill 安装方式发现随包分发的 Skill、`flow-core`、声明式规则和模板，并在隔离环境中使用 Claude Code 跑通需求到验收的 P0 主链路。试点必须证明安装资源使用相对位置、不依赖开发机源码仓库，也不会污染现有项目、全局配置或凭据。

**Blocked by:** 09: 建立结构检查与 CI 治理

**Status:** ready-for-agent

- [ ] 标准安装命令能够安装并发现 P0 所需的 Skill、CLI、规则和模板。
- [ ] 安装后的运行时只依赖随包资源和项目规则基线，不依赖开发机源码仓库路径。
- [ ] 升级说明只要求使用约定的通用更新命令，不引入自定义安装器或升级器。
- [ ] Claude Code 在隔离项目中能够发现并调用 `project`、`requirements`、`prd`、`dev` 和 `acceptance` Skill。
- [ ] 真实小项目可以完成需求、grilling、人工排期、PRD、批准、开发、验证、人工验收和收尾主链路。
- [ ] 试点保留状态历史、人工确认、PRD hash、原始验证输出、版本信息和验收收尾结果。
- [ ] 试点不修改当前全局配置、凭据或已有项目；不依赖 Claude 专属 Hook 或内部 API。
- [ ] 端到端验收记录 P0 通过条件和未承诺的其他 Agent/操作系统兼容性边界。
