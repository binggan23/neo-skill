# 01: 绑定并持久化上游进度来源

**What to build:** 在项目接入流程中，让项目负责人配置当前项目的上游项目和远端进度来源，并在确认后将配置持久化到项目指引中。用户可以不配置上游而继续接入；已有绑定、信息不完整或用户拒绝时不得静默覆盖或伪造配置。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 接入流程询问是否绑定上游，并收集上游 URL/项目标识和远端进度来源。
- [ ] 写入前展示待记录内容和目标文档，取得用户明确确认后才持久化。
- [ ] 优先写入项目级 Agent 指引；没有时使用 README 的明确配置区块。
- [ ] 保留目标文档的无关内容，不做整文件覆盖。
- [ ] 覆盖用户拒绝、信息不完整、已有绑定和无上游项目等分支，并明确提示未配置状态。
- [ ] 通过文档契约或等价黑盒测试证明配置结果和保留行为。
