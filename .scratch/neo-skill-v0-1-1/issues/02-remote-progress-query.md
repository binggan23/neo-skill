# 02: 查询远端上游进度

**What to build:** 提供一个用户可调用的进度查询能力，从项目指引中的上游绑定或用户本次提供的临时信息定位远端资料，并生成可核查的进度报告。报告必须把远端已发布事实、进行中事项、来源和不确定性分开表达，不把本地业务内容当作上游证据。

**Blocked by:** 01: 绑定并持久化上游进度来源

**Status:** resolved

- [x] 从项目指引读取上游绑定配置，仅用于定位远端 URL/标识和进度来源。
- [x] 支持缺少持久化绑定时由用户临时提供查询信息，且不自动写回项目文档。
- [x] 报告已发布/已完成的远端事实与进行中/开放事项，并标注来源。
- [x] 对不可访问、不完整、过期或相互矛盾的远端证据明确报告不确定性。
- [x] 不读取本地代码、业务文件、Issue 草稿或其他正文来推断上游进度。
- [x] 使用受控远端资料或等价测试替身验证报告分类、来源和不确定性行为。
